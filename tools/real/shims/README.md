Stand-ins that let SYNFI's own unmodified code (../synfi, pinned commit) run in this environment, where
`ray`, `python-sat` and `sympy` cannot be installed. They change execution, not semantics:

* `ray`: runs every `@ray.remote` function/actor call sequentially in-process (`ray.get` returns the value).
* `pysat.solvers.Minisat22`: the same method names (`add_clause`, `solve`, `get_model`, `delete`) backed by the
  pure-Python CDCL solver `tools/fastsat/scripts/minicdcl.py`. Only satisfiable/unsatisfiable is used by SYNFI.
* `sympy`: SYNFI's fault-injection path imports `Symbol` only as a type annotation; the stub is never called.
  The cell-library generator (which really uses sympy) is not run; the pinned autogenerated library is used.

These are test doubles for running the reference tool, not part of GlitchSAT.
