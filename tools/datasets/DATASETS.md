# Public data for building and validating GlitchSAT in software

Compiled 2026-11-20/21. Every entry below was opened and checked at its source page or repository (commit hashes read with `git ls-remote` / blob-less tree listings). Nothing here was measured by this project.

**Kind labels**

| Label | Meaning |
|---|---|
| SILICON | Measured on a real chip or FPGA by the cited authors |
| SIM | Simulation or characterisation data (for example Liberty timing tables from SPICE) |
| CIRCUIT | Netlists or RTL, no measurement |
| RESULTS | Published tool results to compare against (transcribed into `published_results.json`) |

**Licence actions**: `fetch` = downloaded by `fetch_datasets.sh`; `opt-in` = downloaded only with a flag; `manual` = not downloaded, licence unclear or host blocks scripts (listed by `fetch_datasets.sh --manual`).

## Headline finding on physical data

No open raw data set of glitch campaigns (success / crash / no effect versus glitch offset, width or voltage on an MCU or FPGA) was found on Zenodo, IEEE DataPort or in the obvious GitHub tools. Checked and empty for this purpose: `MKesenheimer/fault-injection-library` (PicoGlitcher; ships images only, no campaign databases), `hextreeio/faultier` (firmware only), `SySS-Research/picoglitcher-lpc1343`, `lowRISC/ot-sca` (side-channel traces only, no FI data), Zenodo records 7820870 (EMFI preprint PDF only) and 2165679 (thesis PDF), arXiv 2609.00502 GlitchLab (no data link). Real-silicon numbers therefore come from published tables (ranks 6, 7, 8, 11), which must be transcribed with citation. That limits calibration to sanity checks of rates and fault multiplicity, not fitting.

## Notes for use

- Real-silicon items (6, 7, 8, 11, 16, 17) are published tables or small printed outputs, not raw data. Quote them as "reported by", with the table or slide number.
- `published_results.json` holds the tables for items 1, 3, 9 and 10. Every value there is transcribed from a PDF text layer; check each value you quote against the rendered page.
- Copyleft or restricted sources (ITC'99 EUPL-1.2, ChipWhisperer GPL, FIVER non-commercial) stay in `$HOME/GlitchSAT-data`, outside the Apache-2.0 repository.
- `fetch_datasets.sh` runs in an Ubuntu 24.04 VM. Git sources need only github.com. The direct downloads need `zenodo.org`, `rtfm.newae.com`, `eprint.iacr.org` (and `artifacts.iacr.org` with `--noncommercial`) on the network allowlist; `--github-only` skips them (it then needs only `github.com`), and `--hosts` prints them. Static files are checked against a sha256: a pin in the script where one is written, otherwise the first fetch's value kept in `$GLITCHSAT_DATA/FIRST_FETCH.sha256`; the two NewAE tutorial pages change upstream and stay unpinned.
