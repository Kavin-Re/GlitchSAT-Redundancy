## What this project is, honestly
A reproducible fault-injection analysis toolkit with a solver cross-checked against two other tools on the same fault model, a four-act dashboard (break it, fix it, prove it, lay it out) and sky130 flow-demo layouts of the example designs (open-source tools through DRC/LVS checks; not signed off, never fabricated). It teaches one concrete lesson: a duplicated countermeasure that shares one decision net still falls to a single fault, and whether a "safe" design stays safe (within the model) can depend on how synthesis maps it.

CORRECTED 2026-11-20 (agent P01a, `research/c6/p01/P01_REPORT.md`, `docs/report/WHY_TWO_FLIPS.md`; the earlier text called this a Yosys-build/version effect, which was an error): the stored netlist's header also reads Yosys 0.33, so stored-vs-apt is a flow/source difference (one mux per bit, 68 gates). The root cause is the encoding: the armed word 0xCC differs from 0x96 in bits {1,3,4,6}, owned by only two of the three comparator copies, so two flips of next-state stems can turn the cycle-0 load of CC into 96. Re-encoding that one constant to 0xA5 (`rtl/v2e.v`) gives 3 1 1 3 3 3 3 3 over the 8 `--synth-sweep` flows (v2: 2 1 1 2 2 2 2 2; MEASURED, apt 0.33, re-verified by the lead 2026-11-20); the 1s are flows that merge the copies (opt_merge / flatten before ABC), which no encoding fixes. Encoding sets the floor (idle word touches 2 of 3 copies => 2 flips); the synthesis flow decides whether the floor is reached (1 when a flow merges the copies). A build or flow difference changes the netlist, not the underlying weakness. Re-checked on this machine: the same `scripts/synth.sh` gives 85 gates (40 AND, 25 OR, 20 NOT, 8 DFF; a 2-fault attack exists) with apt Yosys 0.33 and 83 gates (37 AND, 25 OR, 20 NOT, 1 MUX, 8 DFF; no 2-fault attack) with conda Yosys 0.38 (build string `0.38+92`, the `formal` environment). Build differences (H5, 2026-11-20, MEASURED): on the plain flow at <=2 flips apt Yosys 0.33 (85 gates) gives an attack, conda 0.38 and Docker/Debian 0.52 (83 gates each) do not; but conda 0.38 gives 2 on three other flows (P01a), so this is not a version immunity. Verdicts belong to a netlist hash and flow. CI on another Yosys build may therefore not reproduce `ci/expected_reproduce.json`.
