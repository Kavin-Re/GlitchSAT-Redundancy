What we did NOT show

  • Not a real product. This is a tiny toy lock design, built for the experiment.
  • Nothing physical. A “flip” is a modelled bit flip for one clock tick inside a computer check. No chip was glitched.
  • Not “safe”. A digit is the smallest attack the solver found. Below it we can only say: no attack found within the bound (6 ticks, search limit 3 flips).
  • One recipe family. All builds come from one open-source synthesis tool (Yosys 0.33 on this dial). Other tools were not tried.
  • Build recipes are not independent. They are variations of each other, so agreeing rows are not separate confirmations.
  • Not every combination. Where nobody ran the check, the dial says “not measured”. No number is filled in by guessing.
  • Nothing established as new. The effect that synthesis can weaken redundancy is known from earlier work.
