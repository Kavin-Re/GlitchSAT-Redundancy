# Analogies from other fields
Each analogy is a teaching aid, not evidence. Every one has "where it breaks".

1. **Three locks on one hinge (carpentry).** Three strong locks on a door, but all the screws that hold the hinge are shared: remove the hinge and the door opens whatever the locks say.
   *Breaks:* a hinge attack is physical and obvious; in the toy, the "hinge" is one wire that looks like any other. Also the toy's flip is a momentary lie, not a removal.
2. **Two nurses, one chart (nursing).** Two nurses double-check a dose, but both read the same wrongly copied chart. Two signatures, one mistake upstream.
   *Breaks:* nurses are people who may notice oddities; wires do not. The error here is upstream of the checks, while in the toy the error is downstream, after the checks have answered.
3. **Three smoke alarms on one battery or breaker (home safety).** Three alarms, one power source: one tripped breaker silences all. (This is also the analogy the search summary suggested, UNVERIFIED.)
   *Breaks:* a power loss silences alarms for a long time; the toy flip lasts one moment. And alarms detect a danger, while the toy checks a code.
4. **Two signatures, one signer (law).** A contract needs two witnesses, but one person signs for both. Count of signatures is not count of independent opinions.
   *Breaks:* a forged signature is a human deception; the toy has no deceiver inside the circuit, only a wire that says the wrong thing.
5. **Three accountants, one spreadsheet (banking).** Three accountants verify the total, but all read the same cell, which contains one typo.
   *Breaks:* accountants may question a strange number; the door just obeys. Also the typo is a stable error, a flip is momentary.
6. **Three crops, one river (farming).** Three fields planted with different crops to spread risk, but all irrigated from one canal: a blocked canal kills all.
   *Breaks:* crop failure takes days and is gradual; the toy fails instantly. Different crops also add diversity, which the toy's copies lack (identical guards).
7. **Three exam markers, one answer key (teaching).** Three teachers mark the same paper, all using the same answer key with a wrong answer in it. Agreement among markers proves nothing about the key.
   *Breaks:* a wrong key is wrong every time; a flipped wire lies only briefly.
8. **Same recipe, different kitchen (cooking), for the tool twist.** One recipe, but the kitchen assistant combines steps to save time, so two dishes now share a pan. The plan was fine; the finished kitchen shares more than the plan said.
   *Breaks:* a cook uses judgement; the building program applies rules. And the toy says only that one program version merged wires and another did not, not that merging is a mistake.

General limit: all of these suggest the fault is an attack by someone. The page models only a bit flip and makes no claim about how a flip could happen.
