### 7. N6 / N7 / N14: `--consumer-bits` syntax (FIXED, behaviour change documented)
MASK = `0x..`, `0b..`, plain decimal (CLI string = TOML int = TOML decimal string: `3` = mask 3 = bits 0,1). BIT LIST = `bits:3,5`, `bits:0-3,6`, `[3,5]` (TOML list too); ranges need both ends (`1-` refused). The old bare list form with `,` or `-` (`0-3,6`) is still read as a bit list because existing tests/examples use it and it cannot be mistaken for a decimal. Behaviour change: the bare single decimal string `"3"` used to be bit 3 (CLI/TOML-string) and is now mask 3. Ranges are turned into masks arithmetically (no loop); bit index > 4095 or a mask wider than 4096 bits is refused immediately; `--consumer-bits bits:0-100000000` exits 3 in well under a second (was: no result after 60 s). Width check against the real output follows as before ("beyond the N-bit output", exit 3). Tests: 17 accepted forms, 31 rejected forms (each < 1 s), CLI/TOML agreement.
### 8. N9 / N10 / N12: timeouts and cleanup (FIXED for the cases below)
- `--timeout-s`: the worker is started in its own session; at the deadline `os.killpg` kills worker + yosys + abc; the worker's `TMPDIR` is a directory the parent removes, so `fbwt_*` dirs created by a killed worker go too. Test with a fake `yosys` (sleeps with a grandchild `sleep`): exit 2 in about 3 s, no process left, temp dir empty.
- Parent killed: SIGTERM/SIGHUP are turned into `SystemExit` in `cli.main` (handlers restored afterwards) so `finally` runs: worker group killed, temp dirs removed (test). SIGKILL of the parent: the worker polls its parent pid every 0.5 s and then SIGKILLs its own process group (test: fake yosys and its child gone within 10 s). `prctl(PR_SET_PDEATHSIG)` is used only for the direct yosys child of the in-process path (not for the worker: it would kill the worker but orphan abc).
- N10: `analyze()` removes its temp dir in a `finally` (also for Verilog errors, bad port, bad accept value, bad top); `sweep()` moved `synthesize` inside its `try`. Test: 4 error paths leave 0 `fbwt_*` dirs.
- N12: a Verilog path with a space works (quoted token); test passes.
- Not fixed: SIGKILL of the parent leaves the `fbwt_w_*` dir (only a handler-less kill can; the worker is killed, the dir stays); on a platform without `/proc`/Linux semantics the group-kill relies on POSIX `killpg` only (Windows not supported/tested).
### 9. N8: `--max-flips` cost (FIXED by cap + engine cap)
